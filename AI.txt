## Структура ИИ и перемещения

Каждая группа при необходимости запускает алгоритм 
**A*** для поиска пути на небольшие расстояния. 
Операция нахождения разницы между координатами 
выполняется жадным алгоритмом и используется только для 
отдельных юнитов.

Если юнит состоит в группе, то для него основным 
алгоритмом поиска пути всегда является **A*** группы.

### Приоритеты поведения юнита

Высший приоритет имеют приказы и задачи группы.

При отсутствии активных приказов, waypoint'ов и в 
состоянии спокойствия каждый юнит может самостоятельно 
выбрать тайл для перемещения с помощью жадного алгоритма.

Это может использоваться, например, для:

* занятия укрытия;
* перемещения к ближайшему укрытию;
* перемещения к стене;
* выбора безопасной позиции;
* других подобных локальных действий.

То есть юнит способен самостоятельно выбрать тайл для 
перемещения, даже если группа в данный момент не дала 
ему конкретный waypoint.

## Unit AI

Каждый юнит имеет собственный **Unit AI**, который отвечает
за выполнение приказов и локальное поведение.

Unit AI умеет:

* выполнять приказы;
* двигаться с помощью жадного алгоритма;
* избегать препятствий;
* выбирать локальные цели;
* при необходимости запрашивать дополнительный waypoint;
* отслеживать состояние застревания.

При простом движении используется жадный алгоритм.

Если у юнита есть активный запрос на жадное перемещение, 
он может изменять угол движения для обхода препятствий.

Если жадный алгоритм не может нормально продолжить 
движение, юнит должен включать запрос на перемещение с помощью **A***.

При простое CPU может использоваться для расчёта локального поведения.

---

## Group AI

**A*** всегда должен храниться и вызываться из **Group AI**.

Group AI отвечает за:

* запрос пути;
* хранение пути;
* управление waypoint'ами группы;
* перестроение пути при необходимости.

То есть A* является именно групповым механизмом поиска пути.

---

## Жадные запросы

Жадные запросы должны использоваться только для целей, 
которые находятся в прямой видимости.

Перед выбором такой цели необходимо выполнять проверочный луч.

Например, юнит может искать ближайшее укрытие 
среди доступных и видимых вариантов.

Если подходящих укрытий в прямой видимости нет, 
юнит может продолжать перемещение другим локальным способом.

---

## Проблема с группой и A*

Есть проблема:

если стартовая точка A* не видна напрямую, один
юнит из группы может застрять.

Например, один юнит группы находится в позиции, 
из которой следующий waypoint недоступен напрямую, 
хотя остальные юниты способны продолжить движение.

Возникает вопрос:

**как решить эту проблему?**

Первоначальная идея — перед вызовом A* собирать 
всех юнитов группы в одну точку с помощью жадных waypoint'ов.

Но это требует отдельного решения.

Другой вариант — каким-либо образом сделать путь или 
waypoint'ы группы доступными юнитам, но хранение пути 
для каждого юнита может оказаться слишком дорогим.

Это пока остаётся нерешённой проблемой.

## Менеджер движения группы

Ранее описываемая структура фактически была **менеджером движения группы**.

Но AI будет сложнее, чем простой расчёт маршрута 
между двумя точками и расстановка по этому маршруту waypoint'ов.

Помимо расчёта маршрута необходимо учитывать:

* жадное движение;
* прямое тайловое перемещение;
* локальное избегание препятствий;
* индивидуальное состояние каждого юнита;
* ситуации, когда отдельный юнит перестаёт нормально 
следовать маршруту.

При этом чрезмерное количество прямых перемещений по 
тайлам также может легко сломать движение.

---

## Застревание и дополнительные waypoint'ы

У каждого юнита должны быть динамические таймеры, 
позволяющие определить, что юнит застрял.

Если юнит долго не может нормально продолжить движение, 
он должен иметь возможность:

1. запросить дополнительный waypoint;
2. изменить локальное направление движения;
3. при необходимости вернуться к предыдущему waypoint;
4. снова продолжить движение от него.

Предыдущий waypoint, к которому юнит может вернуться, 
**обязательно должен быть видимым и достижимым**.

Таким образом, юнит не должен бесконечно пытаться пройти 
через один и тот же участок, если локальное движение не работает.
